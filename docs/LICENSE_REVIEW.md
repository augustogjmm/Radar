## Pendiente de decisión del titular

**No se agregó una licencia nueva** porque cambiaría los permisos que terceros tienen para copiar, modificar o redistribuir los trabajos. Antes de publicar una licencia abierta, revisar: autoría de cada componente, código derivado de terceros, dependencias y si se desea permitir uso comercial.

Opciones conceptuales (no elegidas):

- Mantener repositorios visibles sin una licencia de reutilización explícita.
- Elegir una licencia permisiva para software completamente propio si se desea facilitar su reutilización.
- Elegir copyleft para software propio si se pretende que versiones derivadas se distribuyan con condiciones recíprocas.
- Separar código de terceros y cumplir exactamente los términos del origen antes de relicenciar.

Se recomienda no asignar una licencia única indiscriminadamente a los doce repositorios. La selección puede ser distinta para un portfolio personal, un prototipo experimental y una adaptación de un proyecto externo.
